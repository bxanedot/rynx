Player expansion/retraction releases at ±1.1 expansion units per second. Navigation uses a 28dp vertical-swipe threshold and a 2.1-tabs-per-second horizontal fling threshold. Springs are interruptible and retain their current velocity. AMOLED keeps the same interaction/motion tree while omitting optical effects. These headless checks do not establish device frame pacing, optical equivalence or reference animation fidelity.

All navigation-specific values in `RynxNavigationMotionSpec` are authored defaults, not values measured from Apple or Vyon recordings. The supplied app had no reference recordings for this navigation behavior, so frame-by-frame trajectory parity remains unverified.
