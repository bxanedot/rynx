# Platform roadmap

P0 Android phones: active. P1 tablets, P2 desktop, P3 TV, P4 Wear and the planned iOS/iPadOS port are gated on completed Android phone acceptance. Existing desktop work is paused, not deleted. No non-Android platform is being expanded.

Milestone A: Android app, common KMP UI/domain targets, lifecycle host, local file access and Media3 service introduced. All Rynx application code is Kotlin; shared UI/domain lives in `commonMain`, while Android OS integration stays in Kotlin `androidMain`/the Android host. Shared iOS Kotlin/Native targets and the GlyphStudio KMP renderer are declared for the later port; there is no iOS host app and no Apple-toolchain build/runtime validation. Build/device results are recorded separately in ANDROID_VISUAL_RESULTS.md and ANDROID_AUDIO_TESTS.md. Database, DI beyond explicit construction, provider integration and navigation remain incomplete.

Milestones B–I remain incomplete: Apple Music-style screens/motion, live InnerTubeX playback, library/offline, Spotify, audio/lyrics, advanced scope, visual comparison and release readiness. The active Android chain is InnerTubeX → NewPipeExtractor; the current provider/artwork slice builds and passes deterministic tests. Live YouTube source and audible device validation have not passed. YouTube.js is not integrated because no Android/Kotlin host is configured. NewPipe's GPL release obligations remain part of the source/notice plan. eXcor was removed from the active project by user request; see `../archive/EXCOR.md`. No completion gate has passed. Compile API 37 and target API 36 are used by Rynx.
